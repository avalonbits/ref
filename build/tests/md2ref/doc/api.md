# API

## `frob(int x)` {#frob}

Frobs *x*. Back to [the start](index.md).

| Name | Meaning |
|------|---------|
| `x`  | the value to frob, which may be quite long and so wraps inside its column when the table is wider than the screen allows |
| `y`  | [unused](#frob) |
